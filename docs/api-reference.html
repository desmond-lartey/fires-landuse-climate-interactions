API reference

Custom function reference

Every non-built-in function used across the five pipeline scripts, documented with its parameters, return type, and the EE operations it wraps. Built-in Earth Engine methods (reduceRegion, remap, etc.) are linked to the official EE API docs rather than re-documented here.

processBurnedArea(date, region)

Defined in 01_burned_area_composites.js. Filters MCD64A1 to a one-month window starting at date, mosaics it over region, and returns a binary "burned this month" mask.

ParameterTypeDescription
dateee.DateFirst day of the target month
regionee.GeometryClipping extent (study area)

Returns ee.Image, single-band binary mask (BurnDate > 0, self-masked), tagged with a date property.

sumBurnedAreaForSpecificMonth(month, startYear, endYear, region)

Sums processBurnedArea masks for one calendar month across a year range, producing the climatology count.

ParameterTypeDescription
monthint (1–12)Calendar month
startYearintFirst year of the climatology (2004)
endYearintLast year of the climatology (2024)
regionee.GeometryStudy area extent

Returns ee.Image, pixel-wise count of years (0–21) that recorded a burn in that month, tagged with a month property, cast to double.

sumBurnedAreaForAllMonths(startYear, endYear, region)

Calls sumBurnedAreaForSpecificMonth for all 12 months and sums the results into one all-months composite.

ParameterTypeDescription
startYear, endYearintClimatology bounds
regionee.GeometryStudy area extent

Returns ee.Image, single-band, all-months burn-frequency composite.

calculateBurnedAreaAndFrequency(feature)

Defined in 02_buffer_disaggregation.js. Builds five buffer geometries around one park feature and computes monthly burn frequency, burned area, and normalised burn-exposure metrics for each.

ParameterTypeDescription
featureee.FeatureOne park polygon with an ORIG_NAME property

Returns ee.FeatureCollection, 5 features (one per buffer distance), each carrying the fields listed in the output schema.

Closures over months, burnedAreaImages, bufferDistances (module-level constants set earlier in the script).

harmoniseGlad(img)

Defined in 03_landcover_harmonisation.js. Remaps GLAD native class codes to the shared 9-class scheme using the gladToEsri dictionary.

ParameterTypeDescription
imgee.ImageSingle-band GLAD land-cover image, native codes

Returns ee.Image, single band named landcover, values 1–9 (class 8/Clouds never appears from this source).

remapEsri(image)

Remaps ESRI's 11-class scheme (native codes 1,2,4,5,7,8,9,10,11) onto the same 9-class target as harmoniseGlad.

ParameterTypeDescription
imageee.ImageSingle-band ESRI LULC image, native codes

Returns ee.Image, single band named landcover, values 1–9.

getLandCoverYear(year)

Dispatches to the correct source dataset and harmonisation function based on year, so callers never need to know which underlying dataset serves a given year.

ParameterTypeDescription
yearintAny year 2000–2024. <2000 or non-covered years return an empty (all-zero) fallback image.
Year rangeSourceFunction called
2000–2020GLAD GLCLU2020 v2harmoniseGlad()
2021–2024ESRI Global LULC 10 mremapEsri() after annual mosaic
other—ee.Image(0) fallback

Returns ee.Image, single band named landcover.

getClimateForYear(year)

Defined in 04_climate_integration.js. Builds an 8-band annual-mean climate image from ERA5-Land, with unit conversions already applied.

ParameterTypeDescription
yearintCalendar year, filtered Jan 1–Dec 31

Returns ee.Image, 8 bands: Tmean_C, Tmin_C, Tmax_C, Tdew_C, Precip_mm, SurfaceP_hPa, WindU, WindV.

calculateBurnedAreaAndLandUse(feature, landCover, year)

Defined in 05_combined_pipeline.js. The main per-park-per-year driver: builds five buffers, then computes burn stats, land-cover histogram, and climate means for each, merging everything into one feature per buffer.

ParameterTypeDescription
featureee.FeatureOne park polygon
landCoveree.ImageOutput of getLandCoverYear(year) for the matching year
yearintBenchmark year, forwarded to getClimateForYear

Returns ee.FeatureCollection, 5 features (one per buffer), each with the full schema documented on the data layers page.

processParkYearSeason(park, year, season)

Defined in 05b_seasonal_fire_rainfall.js. Computes one seasonal (dry or wet) burned-area and rainfall total for one park in one year, the unit consumed by the Step 5 fire–rainfall regressions.

ParameterTypeDescription
parkee.FeatureOne park polygon with ORIG_NAME
yearee.NumberCalendar year of the season's start
season{label, startMonth, endMonth}{label:'Dry', startMonth:10, endMonth:3} or {label:'Wet', startMonth:4, endMonth:9}. When startMonth > endMonth the season is treated as crossing the year boundary.

Returns ee.Feature (no geometry) with properties Park, Year, Season, BurnedArea_km2, Rainfall_mm.
